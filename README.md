# Paradise Nursery

Aplicación de tienda en línea de plantas de interior creada con React, Vite, Redux Toolkit y React Redux.

## Funcionalidades
- Página de inicio con imagen de fondo y botón Comenzar.
- Información de la empresa.
- Catálogo con tres categorías y seis plantas por categoría.
- Carrito con añadir, eliminar, aumentar/disminuir cantidades y cálculo de subtotales y total.
- Indicador dinámico de cantidad de artículos en la navegación.
- Botón de pago con mensaje “Próximamente”.
- Diseño adaptable a móvil y escritorio.

## Instalación
```bash
npm install
npm run dev
```

## Tecnologías
- React
- Vite
- Redux Toolkit
- React Redux
- CSS
